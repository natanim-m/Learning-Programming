# Pygame Snake

A custom Snake implementation written in Pygame featuring custom UI rendering and game-state management.

### Features & Controls
- **Controls:** `WASD` or Arrow Keys to move.
- **Custom UI:** Hand-rolled `Start_Button` and `floatingText` classes using native Pygame surfaces and alpha overlays.
- **State Handling:** Built-in board state rollback and reset logic without tearing down the Pygame display context.
